# 15 cm 台阶上阶验证

当前仿真已完成：双轮腾空、越过台阶边缘、在顶面短腿着陆、撑到正常站姿并制动。入口是 `start_step_jump.cmd`，或在键盘窗口按 `R` 后按 `J`。普通空格仍使用自由跳跃轨迹。

## 原因与修改

原普通跳跃的轮底最高约 15.5 cm，前移只有约 9～10 cm；太晚触发会在蹲伏阶段由机身先撞上立面，太早触发则在台阶前落地。只修改障碍物高度不能解决这个问题。

上阶模式用 0.6 m/s 的速度目标助跑，在轮轴 X≈0.73 m 开始准备。通过 8 cm 深蹲和更强的支撑指令起跳，收腿到 8 cm 目标；轮子接近越过立面后，按髋部与顶面的实际高度差控制着陆腿长。接触顶面后约 0.5 秒撑到 18 cm 腿长，同时减速，再检查是否站稳。

没有提高电机能力。虚拟径向力指令的限幅从普通跳跃的 80 N 调到 400 N，但施加到模型上的仍只有六个电机力矩，继续按原近似 24 V 包络限制：每个髋电机峰值 7 N·m，每个轮电机峰值 2 N·m，并保留转速降额。模型质量、重力、台阶碰撞体、接触参数、物理步长均保持原值。

## 验证结果

`tools/validate_step_jump.py` 从实际 J 键处理路径运行，禁用倒地起身。出生位置以及前后各偏移 2 cm 的三组均通过，起跳后持续仿真到 12 秒。

| 指标 | 三组结果 |
| --- | --- |
| 轮底相对平地的最大高度 | 18.66～18.77 cm |
| 最终轮轴高度 | 约 18.98 cm，等于台阶顶面加轮半径并计接触压缩 |
| 最终机身根部高度 | 约 37.95 cm |
| 最终轮轴 X | 约 1.99～2.03 m，位于台阶内部 |
| 最终前向速度绝对值 | 小于 0.00002 m/s |
| 最大全闭环销轴位置残差 | 约 0.059 mm |
| 最大齿轮角残差 | 约 0.00184 rad |
| 机身/杆件代理碰撞体触地 | 无 |
| 起身补救、外力、控制期间重写位置/速度 | 均无 |

另对 X=0.70、0.71、0.72、0.73、0.74 m 的准备触发位置做了对比，均能最终在顶面站稳；实际 J 模式使用 0.73 m，并自动选择时机。普通跳跃的两次跳跃与回稳回归验证通过。

对标准轨迹的原始非轮 CAD 网格顶点，以 20 ms 间隔抽样检查，未发现顶点进入台阶体积，平地最小间隙约 5.57 mm。这不是杆件自碰撞或完整连续碰撞检查。

## 使用范围与文件

辅助动作针对当前固定台阶：前沿 X=1.5 m、顶面 Z=0.15 m、宽 1.3 m、长 2 m；要求从出生点附近停止且面向 +X 开始。它不提供台阶识别或路径导航。验证结果属于当前估计质量、惯量和电机包络下的仿真，不是实机能力认证。

- 控制实现：`step_jump.py`。
- 完整复核：`python tools/validate_step_jump.py`。
- 参数对比：`python tools/search_step_jump.py --speeds .6 --triggers .70,.71,.72,.73,.74 --all`。
- 数值报告：`results/step15_validation.json`。
- 标准轨迹：`results/step15_trajectory.csv`。
- 过程截图：`media/step15-review.png`。
- 正常速度录像：`media/step15.mp4`。
